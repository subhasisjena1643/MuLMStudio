04 — Rules
✓ DO
Use Inter Tight for all display headings
Use #1B4F99 as the dominant brand color
Keep Signal Red rare — errors and highlights only
Use JetBrains Mono for all code and tensor labels
Keep backgrounds #F4F6FB, not pure white
Use blueprint paper texture in diagrams
✗ DON'T
Mix other blue families (no Bootstrap blue, no sky blue)
Use gradients or drop shadows anywhere
Use red for anything other than errors/warnings
Use font weights above 700 or below 400
Set body text smaller than 13px
Use pure black (#000) — use #1A2030 instead
